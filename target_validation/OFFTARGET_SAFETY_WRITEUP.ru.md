# Оценка безопасности по нецелевым мишеням для топического TRPV1-анальгетика (Track A)

**Статус: черновик для ревью.** Написано по итогам рабочих сессий
2026-08-10/11; каждая цифра здесь прослеживается до конкретного скрипта и
файла с данными в репозитории (пути указаны по тексту), а не восстановлена
по памяти. Перевод английской версии
([OFFTARGET_SAFETY_WRITEUP.md](OFFTARGET_SAFETY_WRITEUP.md)) — при
расхождениях ориентироваться на английский оригинал.

## Аннотация

Прежде чем вкладывать дальнейшие усилия медицинской химии в топический
TRPV1-анальгетик Track A, мы задались вопросом: какие нецелевые белки несут
правдоподобный риск для безопасности и почему. Мы решали это в два этапа.
Сначала — классический подход: семейство сиквенс-паралогов TRPV1 (TRPV2-6)
плюс механистически смежный канал TRPA1, ранжированные по идентичности
последовательности всего белка и аннотированные по литературе. Затем —
поскольку идентичность всего белка плохо предсказывает, насколько
*лиганд-связывающий карман* нецелевого белка реально похож на ванилойдный
карман TRPV1 — мы построили структурный скрининг: полногеномный фильтр по
экспрессии в коже для поиска кандидатов вне семейства TRPV/TRPA, пайплайн
детекции полостей (fpocket) для сравнения геометрии/химии кармана с
ванилойдным карманом TRPV1 без какого-либо докинга, и — для двух главных
хитов — реальный кросс-докинг наших семи валидационных лигандов, чтобы
проверить, переходит ли структурное сходство в сопоставимое предсказанное
связывание. Главный результат: **RARG (рецептор ретиноевой кислоты гамма)**,
уже существующая одобренная топическая лекарственная мишень, никак не
связанная с TRPV1 ни по последовательности, ни по фолду, связывает шесть из
семи лигандов нашего кандидатного класса так же хорошо или лучше, чем сам
TRPV1 — по скоринговой функции докинга, применённой вслепую к неродственному
белку. Это liability уровня целого химического класса, которую стоит нести
дальше как явный counter-screen, а не как сноску.

## 1. Мотивация

Механизм Track A (TRPV1-агонист-опосредованная десенсибилизация,
Qutenza-подобная, топический/локальный путь) делает стандартную
анальгетическую off-target-панель неполной саму по себе. Два разных риска
требуют двух разных методов:

1. **Риск на уровне семейства**: попадает ли препарат в *сиквенс-родственника*
   TRPV1 (TRPV2-6) через тот же самый или гомологичный сайт связывания,
   учитывая их эволюционное и структурное родство?
2. **Риск тканевого совпадения**: попадает ли препарат в *неродственный*
   белок, который случайно (а) имеет карман похожей формы и (б)
   ко-экспрессирован в том же месте действия (кожа, для топического
   продукта), независимо от родства по последовательности?

Стандартная практика неплохо покрывает (1) (паралоговые панели — рутина).
(2) обычно решается эмпирически, поздно и дорого (широкая in vitro панель
уже после появления лида). Мы проверили, может ли структурный
пре-скрининг сузить эту панель *до* оптимизации лида, используя инструменты,
уже имеющиеся в докинг-стеке проекта.

## 2. Анализ на уровне семейства: сиквенс-паралоги TRPV1

### 2.1 Метод

Идентичность паралогов и курируемые safety-liabilities взяты из GraphQL API
Open Targets Platform (`target_validation/build_profile.py`, тот же пайплайн,
что использовался для сравнения шести мишеней в
[comparison_all_candidates.md](profiles/comparison_all_candidates.md)).
Дополнено целевым литературным поиском по каждому паралогу (сессия
2026-08-10) специально для заполнения пробелов, не покрытых API (у TRPV5/TRPV6
изначально не было текста liability).

### 2.2 Результаты

| Паралог | Идентичность посл-ти к TRPV1 | Liability при попадании off-target |
|---|---|---|
| TRPV2 | 45.0% | Роль в развитии сердца, связанная с обработкой Ca2+ (кардиомиопатия у TRPV2-дефицитных растущих сердец); у взрослых полный нокаут и дозирование нейтрализующими антителами не дают явного фенотипа — острое фармакологическое ингибирование выглядит менее рискованным, чем предполагают только данные о развитии. |
| TRPV4 | 41.9% | Зависит от направления эффекта. *Активация* TRPV4 вовлечена в кардиогенный отёк лёгких, но клинический *антагонист* TRPV4 GSK2798745 хорошо переносился при повторном дозировании у пациентов с сердечной недостаточностью, без кардио-лёгочных сигналов безопасности (Cheung et al., 2019, PubMed:30637626) — попадание off-target TRPV1-антагониста в TRPV4 скорее защитно, а не причинно, для этой конкретной liability. |
| TRPV3 | 39.0% | Разделяет с TRPV1 топический сайт действия (кератиноциты/кожный барьер). | TRPV6 | 27.2% | Самый системно значимый паралог при попадании: у нокаутных мышей — нарушенное всасывание Ca2+ в кишечнике, сниженная минеральная плотность костей (остеопороз), алопеция/дерматит, тяжело нарушенная фертильность самцов. Не курировано в Open Targets; добавлено из первичной литературы. |
| TRPA1 | н/п (не сиквенс-паралог; механистически смежный, ко-экспрессированный ноцицептивный канал) | Две независимые клинические программы антагонистов (LY3526318 от Lilly; соединение Roche/Genentech) показали приемлемый профиль безопасности в Phase 1, но обе провалились по эффективности (остеоартрит колена, хроническая боль в пояснице, диабетическая периферическая нейропатия для LY3526318; хронический кашель для соединения Roche/Genentech) — попадание off-target в TRPA1 выглядит нейтральным для безопасности, но это «клинически не доказано для этого показания», а не «клинически подтверждено как безопасное попадание». |

Подробности и источники: [profiles/TRPV1.md](profiles/TRPV1.md) (таблица
«Safety -- off-target family» и приложенный литературный caveat).

### 2.3 Методологическая поправка, сделанная по ходу анализа

Изначальное ранжирование паралогов (по % идентичности всей
последовательности) неявно трактует идентичность как proxy для риска
*сайта связывания*. Это не так. Ванилойдный карман TRPV1 образован
конкретными остатками (Y511, S512, T550, E570, установленными по
крио-ЭМ структурам с капсаицином/RTX/капсазепином) в области
S3/S4/S4-S5-линкера одной субъединицы плюс S5/S6 соседней субъединицы.
Литература указывает, что именно этот регион **структурно и по
последовательности высоко консервативен между TRPV1, TRPV2 и TRPV3** — регион
TM3/4 экспериментально «пересаживаем» между ортологами и переносит
ванилойдную чувствительность на изначально нечувствительные каналы. Это
значит, что реальный риск кармана у TRPV2 и TRPV3 может быть *выше*, чем
намекает идентичность всей последовательности (45%, 39%), тогда как у TRPV4 —
несколько *ниже*, чем предполагают 41.9%, потому что природа уже встроила
селективность в в целом похожий карман. TRPV5/TRPV6, напротив, —
Ca2+-селективные каналы с принципиально другой архитектурой поры/гейтинга —
их низкая идентичность всей последовательности правдоподобно *действительно*
отражает реальную дивергенцию на уровне кармана, в отличие от TRPV2-4.

Именно это наблюдение мотивировало Раздел 3: если идентичность всей
последовательности — ненадёжный proxy для риска кармана даже *внутри*
семейства TRPV, она тем более ничего не говорит о риске off-target *вне*
семейства — для этого нужно сравнивать реальную структуру кармана, а не
родство генов.

## 3. Структурный скрининг нецелевых белков вне семейства TRPV/TRPA

### 3.1 Список кандидатов: экспрессия в коже, druggable, не-TRPV/TRPA

**Исходный список.** RNA tissue-specificity API Human Protein Atlas,
отфильтрованный до генов с классификацией `Tissue enriched` / `Group
enriched` / `Tissue enhanced` для кожи: 604 гена (выгрузка 2026-08-10,
`data/raw/hpa/skin_tissue_specific_genes.tsv`).

**Фильтр druggability.** Каждый ген сверен с Open Targets по `targetClass` и
малой-молекулой `tractability` (те же поля, что в Разделе 2), батчевым
GraphQL-запросом (`target_validation/fetch_skin_targets.py`). У 486 из 604
генов вообще не оказалось target class в Open Targets — это преимущественно
структурные/барьерные белки (кератины, малые пролин-богатые белки, гены
позднего роговеющего конверта, семейство филаггрина) без фармакологического
кармана в принципе, и они были отброшены независимо от силы кожной
специфичности экспрессии.

**Разбиение на ярусы** оставшихся 118 генов по силе доказательства кармана
(`data/processed/skin_offtarget_screen/skin_targets_annotated.csv`; полное
описание в
[skin_offtarget_targets.md](skin_offtarget_targets.md)):

- **Tier 1** (n=26): Open Targets отмечает подтверждённый
  лиганд-связывающий карман (High/Med-Quality Pocket в структурном
  предсказании druggability).
- **Tier 2** (n=59, TRPV3 исключён как уже разобранный): существует реальная
  структура со связанным лигандом или качественный химический зонд, но
  автоматический классификатор карманов явно это не пометил.
- **Tier 3** (n=22): классифицирован в druggable-подобное семейство
  (GPCR/киназа/протеаза/транспортёр) по последовательности, но структурных
  доказательств пока нет.

Этот текст описывает работу, сделанную по **Tier 1**; Tier 2-3 (среди них
есть биологически очевидные кандидаты для топического/воспалительного
контекста — PTGS1/COX-1, рецепторы лейкотриена B4 LTB4R/LTB4R2, HCAR2/HCAR3,
несколько калликреинов) помечены, но пока не проскринены.

### 3.2 Структурное сравнение «карман к карману»

**Инструмент**: fpocket, детектор полостей чисто по геометрии (триангуляция
Вороного/альфа-сферы) — лиганд не позиционируется, поэтому это намного
дешевле докинга и масштабируется на десятки мишеней за минуты.

**Валидация метода.** Сначала запущен на самом TRPV1 (`receptor_AD_raw.pdb`,
фрагмент цепей A+D из PDB 11CK, уже подтверждённый в MD-пилоте времени
резиденции как содержащий истинный ванилойдный карман — см.
`md_residence_time/STATUS.md`). Топовая по внутреннему рейтингу полость
fpocket'а (по собственному скорингу, не только по druggability) независимо
воспроизвела все четыре литературных остатка (Y511, S512, T550, E570), с
druggability score 0.783 и объёмом 758 Å³. Это подтверждает правило
«топ-карман по рейтингу самого fpocket» как способ сравнения для 26
кандидатов — оно не взято произвольно, а сначала проверено на известном
эталоне.

**Получение структур.** Для каждого из 26 генов Tier 1: поиск в UniProt
лучшей по разрешению и по протяжённости покрытой цепи экспериментальной
PDB-структуры (с fallback на AlphaFold при отсутствии; на практике у всех 26
нашлась экспериментальная структура). Один баг пойман и исправлен на этом
шаге: свободнотекстовый запрос `gene:X` в UniProt — не точный фильтр по
символу гена; запрос «FBXW7» тихо вернул неродственный ген антисенс-происхождения
рецептора (FBXW7-AS1/DEspR, accession B0L3A2) вместо самого FBXW7 (Q969H0).
Исправлено проверкой точного совпадения возвращённого primary gene symbol с
запросом перед принятием результата
(`target_validation/fetch_tier1_structures.py`); подтверждено, что остальные
25 генов этим багом не были затронуты.

**Сравнение по «отпечатку».** 8-дескрипторный вектор на каждый обнаруженный
карман (druggability score, объём, hydrophobicity score, polarity score,
charge score, доля полярных атомов, доля аполярных альфа-сфер, средняя
локальная гидрофобная плотность), нормализован z-score по всем карманам всех
структур, сравнён с эталоном TRPV1 по евклидову расстоянию и косинусному
сходству (`target_validation/compare_pockets.py`).

Посчитаны и сверены друг с другом два ранжирования, а не доверие одному:
лучший подходящий карман, найденный *где угодно* на данной структуре (что
даёт преимущество белкам, для которых fpocket нашёл много карманов-кандидатов
— проблема множественных сравнений), и единственный карман, который сам
fpocket ранжирует как лучший (то же правило отбора, что провалидировано на
известном кармане TRPV1, то есть более честное однократное сравнение).
Полные данные и оба ранжирования:
[skin_offtarget_pocket_comparison.md](skin_offtarget_pocket_comparison.md).

### 3.3 Результаты: какие мишени флагать

Три гена оказываются близко к вершине *обоих* независимых ранжирований:
**MMP3, NTF4, BLMH**. Каждый флагнутый хит затем проверен на биологическую
правдоподобность — соответствует ли обнаруженный «карман» реальному
известному сайту связывания малой молекулы, или это, вероятно, артефакт
детекции (например, поверхность белок-белкового взаимодействия,
конформационная бороздка серпина)?

- **MMP3 (стромелизин-1)**: реальный, глубокий, гидрофобный
  Zn-зависимый каталитический карман, высокая druggability (0.839).
  Механистически правдоподобный кросс-реактор для гидрофобного, вытянутого
  ванилойд-подобного лиганда. Также независимо релевантен биологии кожи
  (ремоделирование внеклеточного матрикса, заживление ран). **Флаг, высокая
  уверенность.**
- **RARG**: не лидировал ни в одном из ранжирований по расстоянию (6-е
  место в более честном одноразовом ранжировании), но имеет почти
  максимальную druggability (0.982) и высокое косинусное сходство (0.899) —
  его ранг был занижен в основном из-за большего объёма кармана, чем у
  TRPV1 (1032 против 758 Å³), а не из-за химического несходства. Повышен до
  флага именно на основании биологической правдоподобности: **RARG — уже
  одобренная топическая кожная лекарственная мишень** (тазаротен, для
  псориаза/акне) — попадание off-target здесь конкурирует с уже
  существующим терапевтическим механизмом в той же ткани, а не с
  гипотетическим. **Флаг, высокая уверенность** (и впоследствии — самый
  подтверждённый хит, см. Раздел 4).
- **BLMH (блеомицин-гидролаза)**: умеренная druggability (0.404), но
  клинически заметен, поскольку *низкая* активность BLMH в коже уже
  вовлечена в реальную топически-релевантную токсичность препарата
  (флагеллятный дерматит от блеомицина). **Флаг, умеренная уверенность.**
- **NTF4, CHP2, SERPINB5**: понижены в весе. NTF4 — секретируемый фактор
  роста (лиганд TrkB) — обнаруженный «карман», скорее всего, поверхность
  белок-белкового взаимодействия, а не сайт для малой молекулы.
  Почти максимальный druggability score SERPINB5 (0.995) подозрителен для
  серпина, чья функция опосредована встраиванием реактивной петли, а не
  занятием кармана малой молекулой — вероятный артефакт детекции. По CHP2
  нет сильных априорных данных ни в одну сторону, дальше не разбирался.

Оговорки, специфичные для этого этапа (риск множественных сравнений,
вероятный артефакт фьюжн-белка, обесценивающий результат по ADRB2,
грубость 8-дескрипторного отпечатка по сравнению с истинным 3D-сравнением
формы/электростатики), подробно разобраны в
[skin_offtarget_pocket_comparison.md](skin_offtarget_pocket_comparison.md#caveats)
и переходят в ограничения этого документа (Раздел 5).

## 4. Валидация кросс-докингом: переходит ли структурное сходство в реальное связывание?

Сходство дескрипторов кармана — в лучшем случае генератор гипотез.
Решающая проверка — реально ли лиганды кандидатного класса докируются
благоприятно. Мы передокировали семь валидационных лигандов TRPV1, уже
использованных для калибровки MD-пилота времени резиденции
(`md_residence_time/ligands.py`: resiniferatoxin, phenylacetylrinvanil,
olvanil, arvanil, rinvanil, capsaicin, nonivamide — агонистный ряд,
охватывающий ~5 порядков по EC50 на TRPV1), в MMP3 и RARG, используя тот же
Vina/Meeko пайплайн, уже провалидированный для TRPV1 в
`docking/SMOKE_TEST.md`. Рецепторы: PDB 1SLM (MMP3) и PDB 6FX0 (RARG),
подготовлены `mk_prepare_receptor.py`; бокс докинга центрирован на центроиде
альфа-сфер флагнутого fpocket'ом кармана (+6 Å паддинга). Запущено на двух
инстансах vast.ai параллельно, по одной мишени на инстанс.

| Лиганд | EC50 на TRPV1 (нМ) | Vina score, TRPV1 | Vina score, MMP3 | Vina score, RARG |
|---|---|---|---|---|
| resiniferatoxin | 0.011 | -9.63 | -5.18 | -2.86 |
| phenylacetylrinvanil | 0.09 | -8.01 | -6.70 | **-8.98** |
| olvanil | 0.6 | -7.49 | -6.98 | **-8.73** |
| arvanil | 0.5 | -7.83 | -7.51 | **-9.17** |

| capsaicin | 712.0 | -8.23 | **-8.43** | **-8.59** |
| nonivamide | 1400.0 | -7.60 | -7.70 | -7.97 |

(Vina score в ккал/моль; более отрицательное = сильнее предсказанное
связывание. Жирным — там, где значение совпадает или превышает собственный
TRPV1-скор лиганда.)

**RARG: шесть из семи лигандов докируются так же хорошо или лучше, чем в
сам TRPV1.** Только resiniferatoxin — самый объёмный и структурно сложный
лиганд в наборе, дитерпен — подходит плохо. Применённая вслепую к
неродственному белковому фолду, скоринговая функция Vina ранжирует
большую часть этого химического ряда как сопоставимо или более
комплементарную ретиноидному карману RARG, чем собственному ванилойдному
карману TRPV1. Это независимое подтверждение флага по сходству карманов, а
не просто его повторение.

**MMP3: размерозависимо.** Капсаицин и нонивамид — самые маленькие, самые
простые молекулы в наборе, ближайшие аналоги того, что реально отберёт
MW/logP-окно ZINC diversity-triage Track A (200-450 Да, logP 1.0-4.0, явно
заякоренное на капсаицине — `docking/ZINC_TRIAGE.md`) — совпадают или чуть
превышают свой TRPV1-скор на MMP3. Более объёмные, длинноцепочечные
лиганды стабильно докируются в MMP3 хуже, чем в TRPV1.

**Значение для окна ZINC-триажа.** Риск off-target на обеих мишенях, и
особенно на RARG, сконцентрирован именно в том малом, капсаицин-подобном
химическом пространстве, которое и так отбирает топическое MW/logP-окно.
Это не тот риск, который самоустраняется эвристикой «предпочитать меньшие,
более проникающие молекулы» — скорее наоборот, именно меньшие молекулы
связываются с RARG и MMP3 сопоставимо хорошо.

## 5. Ограничения

- **Генерация гипотез, не подтверждение.** Никакие wet-lab или литературные
  данные о кросс-реактивности не проверялись против этих предсказаний.
  Самовалидация на TRPV1 (Раздел 3.2) доказывает, что fpocket воспроизводит
  *известный* карман; она не доказывает, что сходство дескрипторов или
  Vina score предсказывают *реальное* связывание для неродственного фолда.
  Результат по RARG следует читать как «заслуживает явного
  counter-screen», а не как «подтверждённая кросс-реактивность».
- **Vina score — приближённая, эмпирически подобранная скоринговая
  функция**, а не свободная энергия. Сравнение абсолютных значений между
  разными рецепторами/размерами карманов имеет свои оговорки сверх обычного
  использования Vina для ранжирования внутри одной мишени; убедительность
  результата по RARG — в его согласованности по 6 из 7 лигандов, а не в
  каком-то одном значении по отдельности.
- **Одна статическая конформация рецептора на мишень**, без induced-fit или
  ансамблевого докинга. Структура RARG (6FX0) потребовала
  `--allow_bad_res --default_altloc A` из-за одного неразрешённого
  бокового радикала Tyr180 и семи остатков с альтернативными
  конформациями — обычная кристаллографическая деталь, но напоминание, что
  это единичные экспериментальные снимки.
- **8-дескрипторный отпечаток fpocket грубый**: нет 3D-выравнивания формы
  кармана, нет явной электростатики, нет знания о том, какие остатки
  вступят в стерический конфликт с конкретным лигандом. Специализированный
  инструмент сравнения карманов (IsoMIF, KRIPO, ProBiS) был бы строже;
  fpocket выбран именно потому, что не требовал нового инструментария и
  считает десятки мишеней за минуты.
- **Массовая экспрессия по HPA/GTEx не разрешает экспрессию в
  ганглиях задних корешков/периферических нервных окончаниях** — ткани,
  наиболее релевантной месту действия топического анальгетика. Мишень
  может быть значимой на нервном окончании, не будучи «обогащённой по
  коже» в массовой RNA, и наоборот. Эта оговорка также применима к
  исходному профилю TRPV1 (Раздел 2) и унаследована здесь, а не нова для
  этого этапа.
- **Структуры GPCR могут быть искажены фьюжн-конструкциями
  кристаллизации.** У ADRB2 топовый по рейтингу fpocket карман имел
  неправдоподобно низкую druggability (0.017) для валидированного
  ортостерического сайта GPCR, что говорит о том, что топ-выбор fpocket —
  скорее артефакт фьюжн-белка (T4-лизоцим/BRIL), чем настоящий карман;
  отрицательный результат по ADRB2 стоит обесценить, а не читать как
  подлинное несходство.
- **Проскринен только Tier 1 (26/118 генов-кандидатов).** Биологически
  очевидные боль/воспаление-релевантные кандидаты Tier 2 (PTGS1,
  LTB4R/LTB4R2, HCAR2/3) ещё не прогнаны ни через сравнение карманов, ни
  через редокинг.

## 6. Рекомендации / дальнейшие шаги

1. **Counter-screen по RARG становится стандартным шагом для любого
   кандидата hit-to-lead Track A** в этом химическом ряду, а не
   опциональным довеском — как минимум проверка биоактивности по
   ChEMBL/литературе, в идеале — реальный assay связывания или
   трансактивации RARG перед продвижением соединения.
2. **MMP3 остаётся в watchlist**, с весом в сторону меньших кандидатов
   конкретно (капсаицин/нонивамид-размерный конец ряда).
3. **BLMH остаётся пунктом наблюдения низкого приоритета**; в этом заходе
   не передокирован.
4. Распространить тот же пайплайн (сравнение карманов + редокинг) на
   **боль/воспаление-релевантные кандидаты Tier 2** (PTGS1, LTB4R/LTB4R2,
   HCAR2/3, GPRC5D), если позволит бюджет скрининга — они были отмечены как
   биологически заметные ещё на этапе составления списка мишеней (Раздел
   3.1), но структурно ни разу не проверены.
5. Если кросс-реактивность по RARG подтвердится дальше, стоит рассмотреть,
   меняет ли это стратегию выбора хемотипа для пула ZINC-триажа (вывод
   Раздела 4), а не считать это только downstream counter-screen'ом.
